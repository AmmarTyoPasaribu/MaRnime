# MaRnime 🌌

Website anime modern dengan tema Aurora Dark yang elegan. Jelajahi, lacak, dan kelola daftar anime kamu.

---

## ✨ Fitur

- **Jelajahi Anime** — Cari dan filter anime berdasarkan genre, format, status, musim, dan tahun
- **Detail Anime** — Lihat sinopsis, karakter, staf, relasi, rekomendasi, dan trailer
- **Musiman** — Anime yang sedang tayang per musim dengan countdown episode
- **Watchlist** — Tambah anime ke daftar tontonan (Planning, Watching, Completed, dll)
- **Profil** — Kelola daftar anime dan lihat statistik tontonan
- **Autentikasi** — Daftar dan masuk dengan email & password via Supabase
- **Multibahasa** — Toggle bahasa English / Indonesia
- **Responsive** — Tampilan optimal di desktop dan mobile

---

## 🛠 Tech Stack

| Layer | Teknologi |
|---|---|
| Frontend | Next.js 16, React, TypeScript |
| Styling | Tailwind CSS 4, Custom Aurora Dark Theme |
| Animasi | Framer Motion |
| Data API | AniList GraphQL API |
| Auth & DB | Supabase (Auth + PostgreSQL) |
| Icons | Lucide React |
| Hosting | Vercel |
